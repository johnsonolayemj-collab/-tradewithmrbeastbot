# Reverse Text Bot

A simple Telegram bot that reverses any text you send it.

## Features
- Instantly reverses any text message
- Simple button-based interface
- No data stored, no external links
- Works on mobile and desktop

## How to Use
1. Start the bot with `/start`
2. Type or paste any text
3. The bot replies with the text reversed

Example: `hello` → `olleh`

## Commands
- `/start` — Welcome message
- `/help` — Usage instructions
- `/reverse <text>` — Reverse text directly via command

## Deployment
This bot runs on Railway and is deployed from GitHub.
